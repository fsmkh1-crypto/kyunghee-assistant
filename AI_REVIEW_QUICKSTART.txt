승아 타이머 · AI 연결 테스트

1. ZIP을 새 폴더에 모두 풉니다. EXE와 _internal 폴더를 함께 두세요.
2. KyungheeTimerAIReview.exe를 실행합니다. Python 설치는 필요하지 않습니다.
3. 캐릭터 이미지를 클릭하면 설정이 열립니다. 트레이 아이콘 우클릭의 '설정'도 사용할 수 있습니다.
4. 아래로 내려 'AI 설정'에서 ON을 고르고 본인의 OpenAI API 프로젝트 키를 입력합니다.
5. 'AI 설정 적용'을 누른 다음 '연결 테스트'를 누릅니다.
6. 실행하면 이미지·말풍선과 대화 입력창이 열립니다. 말풍선은 대화, 캐릭터·타이머 영역은 설정을 엽니다.

타이머와 대화창은 항상 다른 창 위에 표시합니다. AI 답변 대기 중에는 기본 대사를 먼저 내보내지 않습니다.
메인 화면에는 시간·상태 숫자를 표시하지 않습니다. 집계와 기록은 계속 유지합니다.
'타이머 얼마나 돌아갔어?', '몇 분째야?', '오늘 얼마나 썼어?', '연속 사용 시간 알려줘'처럼 물으면
API 연결이나 답변 대기와 관계없이 앱의 실제 시간을 초 단위로 즉시 알려줍니다.
이번 실행 경과와 실제 사용·연속 사용·자리비움은 구분해서 안내합니다.
설정과 전체 기록은 트레이 메뉴에서 열 수 있습니다.
말풍선과 캐릭터를 클릭해도 미리 작성된 기본 대사를 넘기지 않습니다.
대화로 설정이나 이미지를 바꾸는 기능은 제거했습니다. 대화는 대화로만 사용합니다.
이미지·설정 변경은 캐릭터를 눌러 여는 설정 화면에서 직접 해 주세요.
화면 위의 🎲를 누르면 이미지를 임시로 바꿉니다. 연속해서 같은 파일은 고르지 않습니다.
옆에 나타나는 ↩를 누르면 현재 타이머 상황에 맞는 이미지로 돌아갑니다.
주사위는 저장된 이미지 설정을 바꾸지 않습니다. 설정에서 이미지를 직접 고르면 그 선택을 표시합니다.
설정의 '추가 세트 ZIP 가져오기'는 번호 없는 default.png·cheer.png 등 10개 역할에도 번호를 자동 배정합니다.
불완전하거나 모호한 역할은 안내하며, 이미 있는 동일 세트와 원본 파일은 그대로 보존합니다.
이전 테스트판 폴더에 추가한 에셋은 그 폴더에 남습니다. 이전 폴더와 원본 ZIP을 보관하고,
새 폴더에서는 같은 에셋 ZIP을 다시 가져오세요. 아직 없는 이미지의 저장된 선택도 지우지 않습니다.

API 키는 이 앱의 마스킹된 입력란에만 직접 입력하세요. 채팅으로 보낼 필요가 없습니다.
기본값은 이번 실행 중에만 사용입니다. '키 기억'을 선택하면 이 Windows 계정의 DPAPI로 암호화합니다.
AI 연결 테스트와 대화는 실제 OpenAI API 요청이며, API 사용 권한·프로젝트 크레딧이 필요합니다.
키가 없거나 인증·네트워크·한도·지연 오류가 생기면 기존 로컬 대사로 계속하며 타이머는 동작합니다.

이 검토용 EXE의 기록·설정·키는 기존 앱과 분리된 아래 폴더에 저장됩니다.
