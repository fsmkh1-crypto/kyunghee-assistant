승아 타이머 · AI 연결 테스트

1. ZIP을 새 폴더에 모두 풉니다. EXE와 _internal 폴더를 함께 두세요.
2. KyungheeTimerAIReview.exe를 실행합니다. Python 설치는 필요하지 않습니다.
3. 승아 캐릭터를 짧게 클릭하고, 상세 정보의 '설정'을 누릅니다.
4. 아래로 내려 'AI 설정'에서 ON을 고르고 본인의 OpenAI API 프로젝트 키를 입력합니다.
5. 'AI 설정 적용'을 누른 다음 '연결 테스트'를 누릅니다.
6. 메인 화면의 '대화'를 눌러 짧게 말을 걸어봅니다.

타이머와 대화창은 항상 다른 창 위에 표시합니다. AI 답변 대기 중에는 기본 대사를 먼저 내보내지 않습니다.
설정의 '추가 세트 ZIP 가져오기'는 번호 없는 default.png·cheer.png 등 10개 역할에도 번호를 자동 배정합니다.
불완전하거나 모호한 역할은 안내하며, 이미 있는 동일 세트와 원본 파일은 그대로 보존합니다.

API 키는 이 앱의 마스킹된 입력란에만 직접 입력하세요. 채팅으로 보낼 필요가 없습니다.
기본값은 이번 실행 중에만 사용입니다. '키 기억'을 선택하면 이 Windows 계정의 DPAPI로 암호화합니다.
AI 연결 테스트와 대화는 실제 OpenAI API 요청이며, API 사용 권한·프로젝트 크레딧이 필요합니다.
키가 없거나 인증·네트워크·한도·지연 오류가 생기면 기존 로컬 대사로 계속하며 타이머는 동작합니다.

이 검토용 EXE의 기록·설정·키는 기존 앱과 분리된 아래 폴더에 저장됩니다.
%LOCALAPPDATA%\KyungheeTimer_AI_Review\KyungheeAssistant
기존 타이머의 원본·기록·설정은 가져오거나 덮어쓰지 않습니다.
기존 앱과 검토용 앱은 구분되는 인스턴스를 사용합니다. 검토가 끝나면 검토용 트레이 아이콘에서 종료하세요.

이 ZIP은 검토용 Windows 패키지입니다. 사용자 키를 포함하지 않습니다.
