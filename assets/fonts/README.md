# Bundled Pretendard desktop fonts

Unmodified Korean-capable static OpenType fonts from Pretendard v1.3.9.

- Official project: https://github.com/orioncactus/pretendard
- Release: https://github.com/orioncactus/pretendard/releases/tag/v1.3.9
- Font source directory: https://github.com/orioncactus/pretendard/tree/v1.3.9/packages/pretendard/dist/public/static
- License: SIL Open Font License 1.1; complete upstream license included as `LICENSE`.
- Upstream license: https://github.com/orioncactus/pretendard/blob/v1.3.9/LICENSE

These are the full Pretendard fonts, not the Latin-only Pretendard Std family.
No font modification, subsetting, or renaming was performed.
