# 승아 타이머 2.1.6-hotfix.1

이 문서는 **Windows 빌드용 소스** 검증 시점의 기록입니다. 실행본의 출처와 Windows 자동 검사 결과는 해당 실행본의 BUILD_INFO.txt와 빌드 보고서를 확인하세요. 기존 설치본을 덮어쓰거나, EXE를 실행하거나, 사용자 프로필을 수정하지 않았습니다. 기준은 2.1.6 배포 커밋 `5dce504c3d53f19b3309e7a51e5b191253a6c50e`입니다.

## 수정 결과

| 상황 | 수정본 동작 |
| --- | --- |
| 23:00부터 다음 날 01:00까지 절전 등으로 관측이 끊김 | 전날과 다음 날에 자리비움을 60분씩 기록합니다. 수동 휴식도 같은 경계로 나눕니다. |
| 23:57부터 00:02까지 입력 없음 | 5분 전체가 자리비움으로 확정됩니다. 전날 3분, 오늘 2분이 되고 현재 자리비움 시계는 5분을 표시합니다. 5분 전에 입력하면 잠정 구간을 집중으로 확정합니다. |
| 백업 복원에서 원본을 옮긴 직후 종료 예외 발생 | 확정 전이면 옮긴 파일을 원래대로 되돌립니다. 롤백에 실패하면 원본과 복구 ZIP을 지우지 않고 앱이 불완전한 프로필을 다시 사용하지 못하게 막습니다. 이미 확정된 복원은 그대로 유지합니다. |
| 상태 파일에서 `session.last_seen_wall`이 `null` | 해당 값을 기본값으로 읽고 확인할 수 없는 세션의 연속성만 초기화합니다. 유효한 일별·과거 통계를 버리지 않습니다. |
| 휴식 알림을 영구적으로 끔 | 통계 화면의 남은 시간과 다음 알림 자리에 ‘꺼짐’을 표시합니다. ‘오늘만 끄기’와 구분되며, 다시 켜면 카운트다운이 돌아옵니다. |

기존 2.1.6 상태·백업도 읽을 수 있습니다. 이미 잘못 기록된 과거 통계는 원래 입력 시각을 알 수 없어 임의 보정하지 않습니다. 2.1.6으로 다시 내려가면 구 버전은 아직 확정되지 않은 무입력 구간의 **날짜별** 보조 정보를 사용하지 않습니다.

## 어떻게 검증했나

- Linux/Python 3.12에서 소스 컴파일 성공. 앱 회귀 **561개 중 464 통과·97 환경 조건 제외·실패 0**입니다. 신규 회귀 34개는 모두 실행해 통과했습니다(자정 17, 중단 복원 6, 상태·알림 표시 7, 새 날짜 정보의 백업 호환 4).
- 가상 시계와 임시 프로필을 사용했습니다. 복원 파일 교체 직전·직후의 `KeyboardInterrupt`와 `SystemExit`, 별도 프로세스가 원본을 옮긴 직후 정리 코드 없이 종료되는 경우, 롤백 재중단·커밋 경계와 폴더 복원을 검사했습니다. 예외를 잡지 못하는 갑작스러운 종료에서는 자동 롤백을 약속하지 않으며, 복구 자료와 재실행 차단이 남는지를 확인했습니다.
- 독립적인 초 단위 입력 모형으로 50개 재현 가능한 임의 일정의 날짜별 집중·자리비움 합계를 대조했습니다. 뉴욕의 서머타임 시작일(23시간)·종료일(25시간)도 각각 확인했습니다.
- Windows 전용·화면 의존 검사는 이 Linux 실행에 포함되지 않았습니다. 실제 Windows EXE, 물리 절전·전원 차단·다중 모니터, 한국어 IME, 실제 API, 실사용 장기 동작은 이 소스에 대해 검증하지 않았습니다. 화면 표시는 실제 UI 갱신 메서드와 모의 위젯으로 확인했습니다. 별도 개발용 에셋 가져오기 시험은 scikit-image가 없어 실행하지 못했습니다. 이 수치에는 이후 별도 브랜치에서 진행하는 GitHub Actions나 Windows 빌드 결과를 포함하지 않습니다.

## Windows에서 사용하려면

1. 현재 설치 폴더와 데이터를 유지하고 ZIP은 **새 폴더**에 풉니다. 필요하면 기존 앱의 백업 기능으로 현재 데이터의 사본을 따로 보관하세요.
2. 기존 타이머를 트레이에서 종료합니다. 64비트 Windows Python 3.12 이상(Tcl/Tk·pip 포함)에서 **BUILD_WINDOWS.cmd**를 실행합니다. 세부 방법은 [로컬 Windows 빌드 안내](LOCAL_WINDOWS_BUILD.md)에 있습니다.
3. 빌드·패키지 검사가 성공한 결과 폴더의 ZIP을 별도 폴더에 풀고 `SeungaTimer.exe`를 `_internal`과 함께 사용하세요. 대화창 버전은 `2.1.6-hotfix.1`입니다.
4. 미완료 복원 경고가 보이면 복구 폴더를 삭제하지 말고 [복구 안내](BACKUP_RESTORE.md)를 따르세요.
