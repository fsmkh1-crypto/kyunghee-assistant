# 낱장 이미지로 이름 붙인 전체 세트 만들기

이 기능은 2.1.5를 바탕으로 한 2.1.6 작업본에 추가했습니다. 기존에 전달한 2.1.5 Windows ZIP에는 포함되지 않습니다. 실행본의 버전과 검증 결과는 함께 제공한 BUILD_INFO와 검사 보고서에서 확인하세요.

## 사용 순서

1. **설정 → 이미지 → 낱장으로 새 전체 세트**를 누르고 사용할 PNG·JPG·JPEG·WebP 파일을 여러 개 선택합니다. 파일 선택을 취소하면 저장하지 않습니다.
2. 이름을 입력하고 평상시·집중 응원·휴식 권유·자리비움·경고·잔소리·퇴근 권유·통계 화면·설정 화면·알림창·프로필의 10개 상황에 이미지를 배정합니다. 같은 그림을 여러 상황에 사용할 수 있고, **이미지 추가**로 파일을 더 고를 수 있습니다. 파일명이 상황을 명확하게 나타낼 때만 배정을 제안하며, 같은 상황 후보가 여러 개면 직접 선택합니다. 각 행에서 미리보기와 실제 경로를 확인하세요.
3. **미리보기 확인**을 누르면 최종 저장 이름을 표시합니다. 10개 상황을 모두 배정해야 **새 세트 저장**을 누를 수 있습니다. 이름이 겹치면 `내 세트 (2)`처럼 번호를 붙입니다. 미리보기 이후 이름·배정·원본 파일이 바뀌면 다시 확인해야 합니다.
4. 저장한 뒤 **이 세트 적용**을 누르거나, 전체 이미지 세트 목록의 **내 세트 · 이름**을 선택하고 적용합니다. 저장만으로 현재 그림을 바꾸지는 않습니다. 앱을 다시 열어도 목록과 선택이 유지됩니다.

전체 세트를 적용해도 기존 상황별 수동 지정은 그대로 우선합니다. 원하는 상황을 새 전체 세트 그림으로 바꾸려면 그 상황에서 **세트 따라가기**를 선택하세요. 적용은 기존 **직전 이미지 변경 취소**로 되돌릴 수 있으며, 저장한 세트 자체는 남습니다. 일반 설정의 미저장 변경 버리기로 이미 저장한 세트를 삭제하지 않습니다.

## 데이터 보존

- 원본 파일은 이동하거나 수정하지 않고 복사합니다. ZIP 가져오기, 기존 숫자 세트와 상황별 이미지 묶음은 그대로 유지합니다.
- 새 전체 세트는 고유 ID로 별도 저장하므로 기존 파일명의 숫자와 충돌하지 않습니다. 같은 이름을 대소문자·유니코드 정규화 기준으로 비교해 중복 이름을 구분합니다.
- 저장 전 원본 이미지와 모든 배정을 검증하고, 저장 도중 문제가 생기면 이번에 만든 파일만 정리합니다. 기존 세트·선택·파일은 유지합니다. 미리보기와 취소는 세트 파일을 생성하지 않습니다.
- 백업의 **이미지** 범주에 새 세트가 포함됩니다. 선택 상태까지 옮기려면 **설정**도 함께 백업·복원하세요. 복원 전 세트의 10개 파일, 크기, 해시, 경로와 ID를 확인합니다. 손상된 세트는 기존 데이터를 교체하기 전에 거절합니다.
- 파일 선택은 한 번에 총 100장까지, 세트에는 상황별 10장을 배정합니다. 파일당 32 MiB, 한 세트 총 256 MiB 이내입니다.

## 검증의 범위

검사는 임시 사용자 폴더와 생성한 테스트 이미지로 수행합니다. Linux의 실제 Tk 창으로 저장·적용·재선택·스크롤·배율을 확인할 수 있지만, Windows 실물 기기의 파일 선택창·한글 IME·다중 모니터 DPI 동작을 대신하지는 않습니다. 패키지의 자체 검사에는 새 세트 생성·저장·적용·재조회·되돌리기도 포함되며, 실제 통과 여부는 해당 빌드의 보고서로 구분합니다.

Windows 후속 확인에서는 서로 다른 폴더의 동명 파일을 함께 고르고, 한글 세트 이름으로 저장한 뒤 앱 재시작과 재선택을 확인하세요. 100/125/150/200% 배율에서 마지막 상황까지 스크롤하고 저장·닫기 버튼이 보이는지, 수동 지정과 세트 따라가기·되돌리기가 의도대로 동작하는지도 확인하세요.
