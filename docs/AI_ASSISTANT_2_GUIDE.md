# 승아 타이머 2.1.2 Windows 사용 안내

2.1.2는 실기에서 확인된 미리보기 탐색, 승인 버튼, 자리비움 시계와 대화 유지 문제를 수정하고 선택형 먼저 말 걸기를 다듬은 버전입니다. 2.1.1의 전체보기 종료 수정도 포함합니다. 기존 대화·기억·설정은 같은 사용자 데이터 폴더에서 이어서 사용합니다. 다운로드는 GitHub 로그인 후 성공한 빌드 실행 페이지의 **Artifacts → seunga-timer-2.1.2-windows-x64**에서 선택하세요.

## 2.1.2 실기 반영

- **이미지 미리보기 이전·다음:** 전체 세트를 따르면 선택한 역할부터 그 세트의 여러 상황 이미지를 둘러봅니다. ‘설정 대상’과 ‘미리보기’ 상황을 구분해 표시하며, 둘러보기만으로 실제 선택이나 저장값을 바꾸지 않습니다. 사용자 이미지가 한 장뿐이면 한 장이라고 표시합니다.
- **승인창:** 적용·취소 버튼은 하단에 남고 긴 설명과 이미지 미리보기만 스크롤됩니다. 작은 화면이나 높은 배율에서도 내용을 읽고 승인 여부를 선택할 수 있습니다.
- **자리비움 시계:** 자리비움 중에는 현재 자리비움 구간의 경과 시간을 표시합니다. 오늘 누적 자리비움 기록과는 다른 값이며, 기존 기록 방식은 유지합니다.
- **평소 대사:** 최근 문장을 우선 피하며 시간대·말투·사용자 대사를 일반 메시지에도 반영합니다. 짧은 목록을 모두 사용한 뒤에는 오래전에 나온 문장부터 다시 사용할 수 있습니다.
- **대화 유지:** 대화창이나 전체보기 창을 닫아도 최신 AI 답변과 대화 흐름을 유지합니다. 새 대화, 명시적 답변 닫기와 기록 삭제는 구분합니다. 중요한 휴식·퇴근 알림과 상황 이미지는 계속 갱신됩니다.
- **먼저 말 걸기:** 기존 켜짐/꺼짐 설정을 유지하고, 정기 대화 간격과 최근 대화 보호를 적용합니다. 사용 방법과 호출 제한은 아래 ‘대화로 타이머 조작하기’를 참고하세요.

## 2.1에서 추가·정리한 기능

- **말풍선은 대화**, **시계·캐릭터는 설정**을 엽니다. 누른 채 움직이면 위젯을 이동합니다. 숨겨도 기록은 계속되며 트레이에서 다시 열 수 있습니다.
- **화면 주사위**는 현재 그림을 임시 변경합니다. 다음 상황에서는 해당 상황 그림으로 돌아갑니다. 지속 고정과 고정 해제도 직접 선택할 수 있습니다.
- 설정은 **타이머·알림 / 모양·글자 / 이미지 / AI·기억·데이터** 탭으로 나뉩니다. 하단에서 저장·미저장 변경 버리기를 선택하며, 화면 이동 후에도 초안을 유지합니다.
- 이미지 가져오기·갤러리 선택은 **즉시 적용**됩니다. 일반 설정의 버리기로 가져온 이미지가 삭제되지는 않습니다. 실제 그림의 출처와 선택 범위를 확인하고 이미지 되돌리기를 사용하세요.
- **추가 세트 ZIP 가져오기**에서 미리보기·충돌·누락·손상 검사를 거쳐 가져옵니다. 같은 번호의 역할별 PNG 또는 번호 없는 완전한 세트를 지원합니다. 10개 역할은 `default, cheer, rest, away, warning, leave, stats, settings, alert, profile`입니다. 원본 ZIP과 내장 그림은 보존합니다.
- 가져온 이미지 팩은 사용자 프로필의 `imported_assets`에 저장됩니다. 기존 설치 폴더에서 식별한 추가 세트는 원본을 보존하며 이전합니다. 설치 폴더 교체 전에 데이터 백업도 권합니다.
- 대화에서 `휴식 이미지를 3번으로 바꿔줘`처럼 요청하면 **범위·미리보기 → 적용/취소 → 실제 결과·되돌리기**로 진행합니다. 모호한 범위는 확인하며 승인 전에는 변경하지 않습니다. 오프라인 선택기와 `/이미지` 명령도 제공합니다. 되돌리기는 이번 실행의 직전 이미지 변경을 대상으로 합니다.
- 취소 후 새 메시지를 보낼 수 있고 늦은 응답은 격리합니다. 실패한 메시지는 **재시도·수정해서 보내기**로 복구합니다. 이미 적용한 동작은 취소로 되돌아가지 않으며 같은 재시도로 중복 실행하지 않도록 완료 내역을 확인합니다. 창 숨기기와 응답 취소는 별도입니다.
- **오늘 상태**는 키 없이 타이머 정보를 조회합니다. 대화 글자 확대·복사, 키보드 출처 열기, 날씨창에서 일회성 도시 조회를 지원합니다.
- 이벤트별 AI 안내·**오늘만 조용히**·**웹 검색 허용**을 선택합니다. 이벤트 기본 대사는 즉시 표시하고, 아직 유효한 AI 결과만 후속 표시합니다. 과거 날짜의 날씨 질문을 현재 날씨로 대신 처리하지 않습니다.
- 대화 기록 저장과 장기 기억 사용은 별도입니다. 옵션 전환 후에도 현재 대화를 유지하며 이전 임시 대화를 자동 영구 저장하지 않습니다. 기억은 수정·고정·중복 확인·글자 수·범위별 삭제를 지원합니다.
- 사용량은 **확정 / 응답 미확인 예약 / 잔여 한도**를 구분합니다. 요청 수는 API 시도 수이며, 비용 추정은 실제 청구액의 엄격한 상한이 아닙니다.
- **사용자 데이터 백업·복원 / 진단 내보내기**는 데이터 탭에서 사용합니다. 이미지 팩 ZIP과 다른 기능입니다. 복원 전 현재 데이터를 백업하고 검증·적용하며, 실패하면 되돌립니다. API 키는 제외하고 진단에는 개인 내용·원본 로그·개인 경로를 포함하지 않습니다. [백업·복원 안내](BACKUP_RESTORE.md)

실제 API 응답·과금과 물리 Windows 환경의 미검증 항목은 [구현·검증 목록](IMPLEMENTATION_CHECKLIST_2_1.md)을 확인하세요.

## 1. 설치와 업데이트

1. 타이머가 실행 중이라면 Windows 알림 영역에서 종료해 주세요. 이전 버전의 이름은 경희 타이머예요. 앱은 한 번에 하나만 실행돼요.
2. Windows용 ZIP을 내려받고 파일을 우클릭해 **모두 압축 풀기**를 선택하세요. 설치 위치로 계속 쓸 폴더를 골라 주세요.
3. 압축을 푼 폴더에서 `SeungaTimer.exe`를 더블클릭하세요. 실행 파일과 `_internal` 폴더는 같은 위치에 두세요. Python을 따로 설치할 필요는 없어요.
4. 기존 타이머 기록, 설정, 사용자 이미지는 `%APPDATA%\KyungheeAssistant`에 있어요. 이 폴더를 그대로 두고 새 실행 파일을 실행하면 기존 데이터를 불러와요. Windows 자동 시작을 쓰는 경우 새 버전에서 자동 시작을 껐다 저장한 뒤 다시 켜서 저장하면 새 실행 파일로 연결돼요.

## 2. 승아에게 첫 메시지 보내기

1. 타이머 위젯의 **말풍선**을 누르거나 알림 영역 아이콘을 우클릭해 **승아와 대화**를 선택하세요. 타이머 창에 포커스가 있을 때는 `Ctrl+Shift+A`로 열 수 있어요. 대화창에서 **API 설정**을 여세요. 알림 영역 메뉴의 **승아 AI 설정**으로 바로 열 수도 있어요.
2. [OpenAI API 플랫폼](https://platform.openai.com/api-keys)에서 사용하려는 프로젝트의 API 키를 발급하세요. 해당 프로젝트에서 선택한 모델을 사용할 수 있어야 하고, API 결제는 [별도 결제 설정](https://platform.openai.com/settings/organization/billing/overview)에서 관리해요.
3. **승아의 AI 대화 사용**을 켜고 **새 API 키**에 키를 붙여넣으세요. **이번 실행에만 보관** 또는 **Windows 보호 저장**을 선택합니다. 보호 저장은 현재 Windows 사용자 계정의 DPAPI를 사용합니다. **연결 시험**은 실제 API 요청이며 사용량이 발생할 수 있어요. 결과를 확인하고 설정을 저장하세요. 키 입력란을 비워 저장하면 기존 키를 유지하고, 등록한 키 삭제는 별도 선택을 사용합니다.
4. 대화창에 `오늘 집중한 시간을 알려줘` 같은 메시지를 적고 **보내기** 또는 `Ctrl+Enter`를 누르세요. **응답 취소**를 누르면 응답 대기를 중단해요. 이미 적용한 동작은 실행된 상태이고, OpenAI에 도착한 요청은 사용량에 잡힐 수 있어요.

메시지를 쓰거나 답을 기다리는 동안 메인 위젯의 승아가 듣는 자세를 보여줘요. 답변이 오면 캐릭터 자세가 바뀌고 위젯 말풍선에도 같은 답변이 나와요. 대화창을 최소화해도 답변을 볼 수 있어요.

- 말풍선은 어두운 둥근 배경, 기본 15pt 흰 글씨, 1.4배 줄 간격으로 표시돼요. 너비는 위젯 배율에 따라 320~420px 범위에서 달라지고, 높이는 글에 맞춰 조절돼요. 캐릭터 주변 배경은 투명하게 표시돼요.
- 긴 답변이나 출처가 있는 답변은 말풍선의 빈 여백까지 눌러 **승아의 답변** 창에서 전문을 읽을 수 있어요. 확장창에서 스크롤, 복사, 출처 열기가 가능해요. 말풍선을 오른쪽 클릭하면 타이머의 평소 표시로 돌아가요.
- 시간은 기본 22pt, 상태는 14pt로 표시돼요. 시간, 상태, 말풍선은 각각 표시하거나 숨길 수 있고, 글자 크기와 색은 위젯 설정에서 조절할 수 있어요.
- 위젯에서 말풍선을 숨긴 경우 트레이 메뉴나 `Ctrl+Shift+A`로 대화를 열 수 있어요. 답변 전문은 대화창에서 볼 수 있어요.

AI 대화, 타이머 이벤트의 AI 응원·안내, 로컬 대화·기억 저장은 각각 기본으로 꺼져 있어요. AI를 꺼 두거나 연결이 끊겨도 타이머의 시간 기록과 기본 알림은 계속 작동해요.

## 3. 웹 검색과 날씨 조회

- `오늘 주요 뉴스 검색해 줘`처럼 요청하면 OpenAI 웹 검색을 사용해요. 검색에 근거한 답변에는 본문 출처 링크와 조회 시각이 붙어요. 검색 결과에 근거가 없으면 최신 정보를 확인하지 못했다고 표시해요. 웹 검색 호출은 API 사용량과 추정 비용에 포함돼요.
- 대화창의 **날씨**를 누르면 기본 지역의 현재 날씨와 단기 예보를 조회해요. 이 버튼은 OpenAI 키 없이 사용할 수 있어요. [Open-Meteo 날씨 API](https://open-meteo.com/en/docs)
- 기본 지역은 **세종시**예요. **API 설정 → 기본 날씨 지역**에서 바꾸거나 대화에서 `대전 날씨 알려줘`처럼 다른 도시를 지정할 수 있어요. 결과에 출처, 자료 기준 시각, 한국 시간 기준 조회 시각을 표시해요. 조회가 실패하면 오류를 표시해요.
- 날씨 조회에는 개인 및 비상업용 Open-Meteo 공개 API가 사용돼요. [Open-Meteo 이용 조건](https://open-meteo.com/en/terms)

## 4. 대화로 타이머 조작하기

| 이렇게 말해 보세요 | 승아가 할 수 있는 일 |
| --- | --- |
| `지금 집중 상태야? 오늘 얼마나 집중했어?` | 현재 타이머 상태와 집계된 시간 설명 |
| `지금 쉬었다 올게`, `자리비움 시작해 줘`, `다시 시작해 줘` | 휴식 또는 자리비움 시작, 현재 타이머 상태에 따라 복귀 요청 |
| `이번 휴식 알림을 미뤄 줘` | 미룰 수 있는 상태라면 현재 설정된 시간만큼 미루기 제안 |
| `휴식 간격을 50분으로 바꿔 줘` | 허용된 범위 안에서 변경 제안 |

타이머를 조작하거나 설정을 바꾸는 요청은 **승아 요청 확인** 창에 변경 내용을 표시해요. 내용을 보고 **적용**을 눌러 주세요.

AI 설정에서 **승아가 상황에 맞춰 먼저 말 걸기**를 켜면 휴식, 자리비움, 복귀, 퇴근 안내 시점과 사용 중 정기 간격에 먼저 말을 건넬 수 있어요. 기존 설정은 그대로 유지하며 기본은 꺼짐입니다. **고급 설정 → 먼저 말 걸기 · 간격과 상황**에서 이벤트와 정기 간격을 고르세요. 기본은 20분, 선택 범위는 5~120분입니다.

상황별 AI 호출도 최소 2분 간격을 두고, 시작 직후에는 정기 호출을 하지 않습니다. 대화 중·작성 중이거나 최근 5분 안에 대화했다면 끼어들지 않습니다. 자리비움과 퇴근 모드에는 정기 대화를 쉬며, **오늘만 조용히**와 기존 요청·토큰·비용 한도를 따릅니다. 이미 한 말과 비슷하거나 새로 할 말이 없으면 말하지 않을 수 있어요. AI가 꺼졌거나 응답을 못 받아도 기본 메시지와 타이머 알림은 계속 작동합니다.

먼저 말 걸기도 API 사용량에 포함됩니다. 대화 맥락과 현재 시간·타이머 요약을 사용하지만, 이 기능이 타이머를 자동으로 조작하지는 않습니다.

## 5. 대화와 기억 관리하기

기본 설정에서는 대화를 앱 실행 중에만 유지해요. **대화 기록 저장**과 **장기 기억 사용**을 각각 선택할 수 있습니다. 저장을 새로 켜도 앞선 임시 대화를 자동으로 영구 저장하지 않습니다. 파일에는 Windows 사용자 프로필의 접근 권한이 적용돼요.

- 대화창의 **기억 관리**에서 저장한 기억을 검색하고, 새 기억을 직접 추가하고, 선택한 기억이나 모든 기억을 지울 수 있어요.
- 저장을 켠 뒤 `오전에는 짧게 답해 달라는 걸 기억해 줘`처럼 요청할 수도 있어요. 저장할 문구를 확인창에서 검토하고 승인하면 기억에 추가돼요.
- **이전 대화 더 보기**를 눌러 대화창에 앞선 메시지를 불러올 수 있어요.
- 삭제할 때 이번 실행의 대화·저장 대화·장기 기억의 범위와 건수를 확인하세요. 기억 관리에서도 선택한 기억을 수정하거나 삭제할 수 있습니다.
- 로컬 저장을 끈 뒤에도 **기억 관리**에서 기존 기억을 확인하고 지울 수 있어요. 기존 대화 기록도 **대화 기록 지우기**로 삭제할 수 있어요.

AI 응답을 요청하면 입력한 메시지와 답변에 필요한 최근 대화, 타이머 요약, 사용이 허용된 기억 등이 OpenAI로 전송될 수 있어요. 타이머 이벤트의 AI 안내를 켜면 앱 실행 중에만 남아 있는 최근 대화도 요청 문맥에 쓰일 수 있어요. 앱의 삭제 기능은 이 PC에 저장된 데이터를 대상으로 해요.

## 6. 모델과 사용량

| 설정 | 사용 방법 |
| --- | --- |
| 모델 | 기본은 `gpt-5.4-mini`예요. 목록에서 `gpt-6-luna`, `gpt-5.6-luna`, `gpt-6-sol`, `gpt-6.1-sol`, `gpt-6.1-terra`, `gpt-6-astra`, `gpt-5.4`, `gpt-5.5`도 선택할 수 있어요. 기존 선택은 유지하며, 프로젝트에서 사용할 수 있는 다른 모델 ID도 직접 입력할 수 있어요. |
| 하루 요청 한도 | 앱에서 시도하는 요청 수를 제한해요. 네트워크나 API 오류가 난 호출 시도도 포함해요. |
| 하루 토큰 한도 | 요청에 필요한 입력 토큰과 응답에 배정하는 출력 토큰을 보수적으로 가늠해 제한해요. |
| 하루 추정 비용 한도 (USD) | 앱이 단가를 아는 모델에 적용돼요. 앱의 추정값과 OpenAI 청구 금액은 다를 수 있어요. |

세 한도는 기본으로 비어 있고 필요한 항목만 입력하면 돼요. 앱의 하루 집계는 Windows 현지 날짜를 기준으로 바뀌어요. **오늘 앱 사용량**에서 **새로고침**을 눌러 현재 집계를 확인하고, 계정 전체 사용량과 청구는 [OpenAI 사용량 화면](https://platform.openai.com/usage)에서 확인하세요.

선택지에 있어도 프로젝트별 사용 권한은 다를 수 있어요. 모델을 선택하면 용도·설정과 앱이 아는 표준 단가를 표시합니다. 실제 연결은 **연결 시험**으로 확인하세요. 모델과 요금 기준은 [OpenAI 모델 안내](https://developers.openai.com/api/docs/models)와 [공식 요금표](https://developers.openai.com/api/docs/pricing)를 참고합니다.

새로 추가한 여섯 모델에는 빠른 대화를 위한 `low` 추론을 적용하며 설정 화면에도 표시합니다. 기존 `gpt-5.4-mini`·`gpt-6.1-sol`의 API 기본 추론과 `gpt-5.6-luna`의 `low` 설정은 유지합니다.

모델 사용 권한과 API 크레딧 적용 여부는 별개입니다. 앱은 계정의 크레딧 잔액이나 적용 여부를 확인하지 않아요. API 조직의 권한·청구 화면을 확인해 주세요. ChatGPT 구독의 API 크레딧 혜택은 [공식 자격·연결 조건](https://developers.openai.com/api/docs/guides/chatgpt-api-credits)에 따르며, 모델을 선택했다고 활성화되지 않습니다.

## 7. 연결이 안 될 때

- 키가 없거나 인증 오류가 나면 **API 설정**에서 올바른 프로젝트 키를 등록해 주세요.
- 모델 접근 오류가 나면 프로젝트에서 그 모델을 사용할 수 있는지 확인하거나 사용할 수 있는 모델 ID를 선택하세요.
- 한도나 결제 오류가 나면 **오늘 앱 사용량**과 OpenAI 프로젝트의 사용량·결제를 확인해 주세요.
- 앱 창이 보이지 않으면 Windows 알림 영역의 승아 타이머 아이콘을 확인해 주세요.
