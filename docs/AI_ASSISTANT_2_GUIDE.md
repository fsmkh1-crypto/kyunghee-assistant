# 승아 타이머 2.0.3 Windows 사용 안내

## 1. 설치와 업데이트

1. 타이머가 실행 중이라면 Windows 알림 영역에서 종료해 주세요. 이전 버전의 이름은 경희 타이머예요. 앱은 한 번에 하나만 실행돼요.
2. Windows용 ZIP을 내려받고 파일을 우클릭해 **모두 압축 풀기**를 선택하세요. 설치 위치로 계속 쓸 폴더를 골라 주세요.
3. 압축을 푼 폴더에서 `SeungaTimer.exe`를 더블클릭하세요. 실행 파일과 `_internal` 폴더는 같은 위치에 두세요. Python을 따로 설치할 필요는 없어요.
4. 기존 타이머 기록, 설정, 사용자 이미지는 `%APPDATA%\KyungheeAssistant`에 있어요. 이 폴더를 그대로 두고 새 실행 파일을 실행하면 기존 데이터를 불러와요. Windows 자동 시작을 쓰는 경우 새 버전에서 자동 시작을 껐다 저장한 뒤 다시 켜서 저장하면 새 실행 파일로 연결돼요.

## 2. 승아에게 첫 메시지 보내기

1. 타이머 위젯의 **승아**를 누르거나 알림 영역 아이콘을 우클릭해 **승아와 대화**를 선택하세요. 타이머 창에 포커스가 있을 때는 `Ctrl+Shift+A`로 열 수 있어요. 대화창에서 **API 설정**을 여세요. 알림 영역 메뉴의 **승아 AI 설정**으로 바로 열 수도 있어요.
2. [OpenAI API 플랫폼](https://platform.openai.com/api-keys)에서 사용하려는 프로젝트의 API 키를 발급하세요. 해당 프로젝트에서 선택한 모델을 사용할 수 있어야 하고, API 결제는 [별도 결제 설정](https://platform.openai.com/settings/organization/billing/overview)에서 관리해요.
3. **승아의 AI 대화 사용**을 켜고 **새 API 키**에 키를 붙여넣은 뒤 **설정 저장**을 눌러 주세요. 앱은 Windows DPAPI로 키를 현재 사용자 계정에 연결해 암호화해요. 나중에 키 입력란을 비워 두고 저장하면 기존 키를 유지해요. 등록한 키를 지우려면 **저장할 때 등록된 키 삭제**를 선택하고 저장하세요.
4. 대화창에 `오늘 집중한 시간을 알려줘` 같은 메시지를 적고 **보내기** 또는 `Ctrl+Enter`를 누르세요. **응답 취소**를 누르면 응답 대기를 중단해요. 이미 적용한 동작은 실행된 상태이고, OpenAI에 도착한 요청은 사용량에 잡힐 수 있어요.

메시지를 쓰거나 답을 기다리는 동안 메인 위젯의 승아가 듣는 자세를 보여줘요. 답변이 오면 캐릭터 자세가 바뀌고 위젯 말풍선에도 같은 답변이 나와요. 대화창을 최소화해도 답변을 볼 수 있어요.

- 말풍선은 어두운 둥근 배경, 기본 15pt 흰 글씨, 1.4배 줄 간격으로 표시돼요. 너비는 위젯 배율에 따라 320~420px 범위에서 달라지고, 높이는 글에 맞춰 조절돼요. 캐릭터 주변 배경은 투명하게 표시돼요.
- 긴 답변이나 출처가 있는 답변은 말풍선의 빈 여백까지 눌러 **승아의 답변** 창에서 전문을 읽을 수 있어요. 확장창에서 스크롤, 복사, 출처 열기가 가능해요. 말풍선을 오른쪽 클릭하면 타이머의 평소 표시로 돌아가요.
- 시간은 기본 22pt, 상태는 14pt로 표시돼요. 시간, 상태, 말풍선은 각각 표시하거나 숨길 수 있고, 글자 크기와 색은 위젯 설정에서 조절할 수 있어요.
- 위젯에서 말풍선을 숨긴 경우 승아 버튼과 자세에 대화 상태가 표시돼요. 답변 전문은 대화창에서 볼 수 있어요.

AI 대화, 타이머 이벤트의 AI 응원·안내, 로컬 대화·기억 저장은 각각 기본으로 꺼져 있어요. AI를 꺼 두거나 연결이 끊겨도 타이머의 시간 기록과 기본 알림은 계속 작동해요.

## 3. 웹 검색과 날씨 조회

- `오늘 주요 뉴스 검색해 줘`처럼 요청하면 OpenAI 웹 검색을 사용해요. 검색에 근거한 답변에는 본문 출처 링크와 조회 시각이 붙어요. 검색 결과에 근거가 없으면 최신 정보를 확인하지 못했다고 표시해요. 웹 검색 호출은 API 사용량과 추정 비용에 포함돼요.
- 대화창의 **날씨**를 누르면 기본 지역의 현재 날씨와 단기 예보를 조회해요. 이 버튼은 OpenAI 키 없이 사용할 수 있어요. [Open-Meteo 날씨 API](https://open-meteo.com/en/docs)
- 기본 지역은 **세종시**예요. **API 설정 → 기본 날씨 지역**에서 바꾸거나 대화에서 `대전 날씨 알려줘`처럼 다른 도시를 지정할 수 있어요. 결과에 출처, 자료 기준 시각, 한국 시간 기준 조회 시각을 표시해요. 조회가 실패하면 오류를 표시해요.
- 날씨 조회에는 개인 및 비상업용 Open-Meteo 공개 API가 사용돼요. [Open-Meteo 이용 조건](https://open-meteo.com/en/terms)

## 4. 대화로 타이머 조작하기

| 이렇게 말해 보세요 | 승아가 할 수 있는 일 |
| --- | --- |
| `지금 집중 상태야? 오늘 얼마나 집중했어?` | 현재 타이머 상태와 집계된 시간 설명 |
| `지금 쉬었다 올게`, `자리비움 시작해 줘`, `다시 시작해 줘` | 휴식 또는 자리비움 시작, 현재 타이머 상태에 따라 복귀 요청 |
| `이번 휴식 알림을 미뤄 줘` | 미룰 수 있는 상태라면 현재 설정된 시간만큼 미루기 제안 |
| `휴식 간격을 50분으로 바꿔 줘` | 허용된 범위 안에서 변경 제안 |

타이머를 조작하거나 설정을 바꾸는 요청은 **승아 요청 확인** 창에 변경 내용을 표시해요. 내용을 보고 **적용**을 눌러 주세요.

**타이머 이벤트에서 AI 응원·안내 허용**을 켜면 휴식, 자리비움, 복귀, 퇴근 안내 등의 시점에 승아가 먼저 말을 건넬 수 있어요. 이때의 호출도 API 사용량에 포함돼요.

## 5. 대화와 기억 관리하기

기본 설정에서는 대화를 앱 실행 중에만 유지해요. **대화 기록과 장기 기억을 이 PC에 저장하고 다음 대화에 활용**을 켜면 Windows 사용자 프로필에 대화와 기억을 저장해요. 파일에는 해당 프로필의 접근 권한이 적용돼요.

- 대화창의 **기억 관리**에서 저장한 기억을 검색하고, 새 기억을 직접 추가하고, 선택한 기억이나 모든 기억을 지울 수 있어요.
- 저장을 켠 뒤 `오전에는 짧게 답해 달라는 걸 기억해 줘`처럼 요청할 수도 있어요. 저장할 문구를 확인창에서 검토하고 승인하면 기억에 추가돼요.
- **이전 대화 더 보기**를 눌러 대화창에 앞선 메시지를 불러올 수 있어요.
- 대화창의 **대화 기록 지우기**로 대화 기록을 지울 수 있어요. 기억은 **기억 관리**에서 따로 지워 주세요.
- 로컬 저장을 끈 뒤에도 **기억 관리**에서 기존 기억을 확인하고 지울 수 있어요. 기존 대화 기록도 **대화 기록 지우기**로 삭제할 수 있어요.

AI 응답을 요청하면 입력한 메시지와 답변에 필요한 최근 대화, 타이머 요약, 사용이 허용된 기억 등이 OpenAI로 전송될 수 있어요. 타이머 이벤트의 AI 안내를 켜면 앱 실행 중에만 남아 있는 최근 대화도 요청 문맥에 쓰일 수 있어요. 앱의 삭제 기능은 이 PC에 저장된 데이터를 대상으로 해요.

## 6. 모델과 사용량

| 설정 | 사용 방법 |
| --- | --- |
| 모델 | 기본은 `gpt-5.4-mini`예요. `gpt-5.6-luna`, `gpt-6.1-sol`을 고르거나 프로젝트에서 사용할 수 있는 다른 모델 ID를 입력할 수 있어요. |
| 하루 요청 한도 | 앱에서 시도하는 요청 수를 제한해요. 네트워크나 API 오류가 난 호출 시도도 포함해요. |
| 하루 토큰 한도 | 요청에 필요한 입력 토큰과 응답에 배정하는 출력 토큰을 보수적으로 가늠해 제한해요. |
| 하루 추정 비용 한도 (USD) | 앱이 단가를 아는 모델에 적용돼요. 앱의 추정값과 OpenAI 청구 금액은 다를 수 있어요. |

세 한도는 기본으로 비어 있고 필요한 항목만 입력하면 돼요. 앱의 하루 집계는 Windows 현지 날짜를 기준으로 바뀌어요. **오늘 앱 사용량**에서 **새로고침**을 눌러 현재 집계를 확인하고, 계정 전체 사용량과 청구는 [OpenAI 사용량 화면](https://platform.openai.com/usage)에서 확인하세요.

## 7. 연결이 안 될 때

- 키가 없거나 인증 오류가 나면 **API 설정**에서 올바른 프로젝트 키를 등록해 주세요.
- 모델 접근 오류가 나면 프로젝트에서 그 모델을 사용할 수 있는지 확인하거나 사용할 수 있는 모델 ID를 선택하세요.
- 한도나 결제 오류가 나면 **오늘 앱 사용량**과 OpenAI 프로젝트의 사용량·결제를 확인해 주세요.
- 앱 창이 보이지 않으면 Windows 알림 영역의 승아 타이머 아이콘을 확인해 주세요.
